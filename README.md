# kant_git_study

## 랜덤 메뉴 돌림판

## 담당 기능

랜덤 돌림판 생성 및 메뉴 선택 기능 담당

## 기능 설명

- 돌림판 칸 개수 랜덤 생성
- 랜덤으로 메뉴 개수 결정
- 음식 메뉴 랜덤 선택
- 선택된 메뉴 랜덤 배치
- 돌림판 실행
- 당첨 메뉴 출력

## 동작 방식

1. 랜덤으로 돌림판 칸 개수 결정
2. 결정된 칸 개수만큼 메뉴 생성
3. 음식 목록에서 랜덤으로 메뉴 선택
4. 선택된 메뉴를 돌림판에 랜덤 배치
5. 돌림판 회전 실행
6. 당첨 메뉴 출력

## 예시

랜덤 칸 개수: 8개

돌림판 구성:

- 치킨
- 피자
- 초밥
- 파스타
- 떡볶이
- 햄버거
- 돈까스
- 짜장면

회전 결과:

오늘의 메뉴: 피자
